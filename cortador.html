Cortador de fundo do Firefox

Corta imagens PNG no tamanho da barra e posiciona GIFs, sem recomprimir nada. Você pode ter várias imagens e vários GIFs na barra ao mesmo tempo.

Arraste uma imagem para cá ou use "Escolher imagem"

Arraste a imagem para enquadrar. Use o scroll do mouse ou o zoom para aproximar. Desligue "Estabilizar" para manter a imagem no tamanho original e arrastá-la pela barra.

Cada "Adicionar à barra" cria uma nova camada, sem apagar as anteriores. Uma imagem estabilizada cobre as que estão atrás dela; para trocar, remova a antiga na lista de camadas abaixo. Toda imagem aberta aqui é guardada na biblioteca.

Arraste um GIF para cá ou use "Escolher GIF"

Arraste o GIF pela barra até a posição desejada. As imagens e os outros GIFs que já estão na barra aparecem de fundo, para você não sobrepor sem querer. Cada "Adicionar à barra" cria um GIF novo; todo GIF aberto aqui é guardado na biblioteca.

Escolha um GIF para gerar o CSS.

Clique numa foto para abrir no editor de imagem. Use o × para excluir da biblioteca.

Clique num GIF para abrir no editor de GIF. Use a ★ para favoritar e o × para excluir da biblioteca.
